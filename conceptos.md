## Conceptos Fundamentales
* **Repositorio:** Es el directorio principal donde se almacenan todos los archivos y el historial de tu proyecto.
  * *Públicos:* Visibles para cualquier persona.
  * *Privados:* Restringidos únicamente para ti y los colaboradores con acceso.
* **README:** Archivo de texto (normalmente `README.md`) que la plataforma lee y muestra automáticamente en la página principal para documentar o explicar el proyecto.

## Gestión de Ramas (Branches)
Son copias paralelas del proyecto que te permiten trabajar de forma segura (offline) sin romper el código original.
* **Rama `master` / `main`:** Contiene la versión original y estable del proyecto.
* **Ramas locales/remotas:** Entornos de desarrollo paralelos para añadir código o hacer pruebas.

## Métodos de Copia
* **Clone:** Copia que descargas directamente a tu equipo local para trabajar *offline*.
* **Fork:** Copia que haces del proyecto original hacia tu propia cuenta de GitHub para trabajar *online*.

## Flujo de Trabajo (Workflow)
1. **Commit:** Registro o "foto" de los cambios específicos que guardas en tu rama local.
2. **Push:** Acción de enviar o "empujar" tus modificaciones locales hacia el servidor remoto.
3. **Pull Request (PR):** Petición formal a través de la interfaz gráfica para que tus cambios sean revisados antes de integrarlos en la rama principal.
4. **Merge:** Integración final. Una vez aprobado el *Pull Request*, se fusionan los cambios para que la rama secundaria y la principal vuelvan a ser idénticas.
