## 3.- Markdown

Markdown es un lenguaje de marca que facilita la aplicacion de formato a un texto empleando una series de caracteres
Markdown nacio como una herramienta de conversion de texto plano a html, tambien es considerado un lenguaje que tiene la finalidad de permitir crear contenido de una manera sencilla manteniendo un diseño legible
